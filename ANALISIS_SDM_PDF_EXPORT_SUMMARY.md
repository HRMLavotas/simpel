Fungsi ini menghasilkan laporan PDF lengkap dengan struktur sebagai berikut:

#### **Header Dokumen**
- Judul: "LAPORAN ANALISIS KEBUTUHAN SDM UPT"

- Unit Kerja
- Wilayah (Provinsi/Kabupaten)
- Tanggal pembuatan

#### **Section 1: Data Internal (Peta Jabatan)**
- Tabel ringkasan: Pegawai ASN, Non-ASN, Batas ABK, Defisit
- Tabel detail posisi jabatan (top 10):
  - Nama Jabatan
  - Kategori
  - Jumlah Eksisting
  - Batas ABK
  - Status Formasi (Kurang/Lebih/Sesuai)

#### **Section 2: Data Eksternal BPS** ⭐ **FITUR BARU**
Semua data BPS yang di-generate sekarang ikut ter-export ke PDF:

1. **Tabel Indikator Utama BPS:**
   - TPT (Tingkat Pengangguran)
   - NEET Pemuda
   - Literasi TIK
   - Sektor PDRB Dominan

2. **Sintesis Data BPS:**
   - Kesimpulan integrasi SDDS & SDGs BPS
   - Analisis urgensi intervensi pelatihan

3. **Data Detail BPS (5 Dimensi):**
   - 🏭 **Profil Industri per Sektor** - Struktur ekonomi per lapangan usaha
   - 👷 **Profil Angkatan Kerja** - Data pengangguran, pekerja informal, upah
   - 🎓 **Data Lulusan Pendidikan** - Lulusan SMK/SMA/PT, potensi peserta UPT
   - 💰 **Kemiskinan & IPM** - Indeks kesejahteraan, Gini Ratio
   - ⚡ **Infrastruktur & Konektivitas** - Elektrifikasi, internet, transportasi

#### **Section 3: Hasil Analisis & Rekomendasi AI**
1. **Kesimpulan Utama (Executive Summary)**
   - Ringkasan analisis AI

2. **Formasi Jabatan Ideal:**
   - Tabel Optimasi Jabatan Eksisting (nama, target, alasan)
   - Tabel Usulan Jabatan Baru (nama, usulan, alasan)

3. **Rekomendasi Rekrutmen:**
   - Daftar posisi prioritas rekrutmen

4. **Program Pelatihan:**
   - Usulan program pelatihan berbasis SKKNI

5. **Pengadaan Sarpras:**
   - Rekomendasi sarana prasarana prioritas tinggi

#### **Footer**

- Timestamp: "Generated by SIMPEL SDM - [Tanggal]"

## 🔧 Technical Details

**Library yang Digunakan:**
- `jspdf` v2.5.2 - Core PDF generation
- `jspdf-autotable` v3.8.4 - Table generation plugin

**Format PDF:**
- Paper Size: A4 (210mm x 297mm)
- Orientation: Portrait
- Margins: 15mm
- Font: Helvetica (built-in)
- Color Scheme: Blue (#2563EB), Green (#22C55E), Gray (#808080)

## 📝 Catatan

- PDF dibatasi maksimal 10 posisi jabatan untuk menjaga ukuran file
- Data BPS dibatasi 12-15 baris per section untuk readability
- Jika data terlalu panjang, akan otomatis terpotong dengan elipsis
- File PDF kompatibel dengan semua PDF reader standar
