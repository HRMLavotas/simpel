# Quick Guide: Sheet SUMMARY dengan Data Agregasi Lengkap

## ⚡ 3 Langkah Mudah

### 1️⃣ Export Peta Jabatan
```
Login → Peta Jabatan → Formasi ASN → Export Semua Unit
```

### 2️⃣ Buka Sheet SUMMARY
```
Buka file Excel → Klik sheet "SUMMARY" (sheet pertama)
```

### 3️⃣ Lihat Data Agregasi
```
Scroll horizontal untuk melihat semua kolom agregasi
```

## 📊 Apa yang Ada di Sheet SUMMARY?

### Data Jabatan (8 kolom)
- Total Jabatan, ABK, Existing, Gap, % Terisi, Status

### Data Agregasi (39 kolom)
- **Status ASN:** PNS, CPNS, PPPK, Non ASN, Total ASN
- **Jenis Kelamin:** Laki-laki, Perempuan
- **Pangkat:** Gol I, II, III, IV, PPPK
- **Pendidikan:** SD, SMP, SMA/SMK, D1-D4, S1-S3
- **Agama:** Islam, Kristen, Katolik, Hindu, Buddha, Konghucu
- **Usia:** <25, 25-34, 35-44, 45-54, ≥55, Rata-rata

## 💡 Tips Penggunaan

### ✅ Untuk Laporan Cepat
```
1. Copy sheet SUMMARY
2. Paste ke PowerPoint/Word
3. Tambahkan chart jika perlu
4. Kirim ke pimpinan ✅
```

### ✅ Untuk Analisis Detail
```
1. Buat Pivot Table dari sheet SUMMARY
2. Pilih dimensi yang ingin dianalisis
3. Buat chart untuk visualisasi
4. Export hasil analisis ✅
```

### ✅ Untuk Perbandingan Antar Unit
```
1. Sort berdasarkan kolom yang ingin dibandingkan
2. Gunakan Conditional Formatting untuk highlight
3. Identifikasi unit dengan performa terbaik/terburuk
4. Buat action plan ✅
```

## 🎯 Contoh Penggunaan Cepat

### Skenario 1: Cek Gap Jabatan
```
1. Lihat kolom "Gap (ABK-Existing)"
2. Sort descending untuk lihat unit dengan gap terbesar
3. Lihat kolom "Status ASN" untuk komposisi pegawai
4. Tentukan prioritas rekrutmen
```

### Skenario 2: Monitoring Pendidikan
```
1. Lihat kolom S1, S2, S3
2. Hitung persentase pegawai berpendidikan tinggi
3. Identifikasi unit yang perlu peningkatan
4. Rencanakan program beasiswa/tugas belajar
```

### Skenario 3: Analisis Demografi
```
1. Lihat kolom "Rata-rata Usia"
2. Lihat kolom "≥55 thn" untuk pegawai mendekati pensiun
3. Identifikasi unit yang perlu regenerasi
4. Rencanakan rekrutmen pegawai muda
```

## ❓ FAQ

**Q: Apakah data di SUMMARY sama dengan Agregasi Cepat?**
A: Ya, menggunakan logika agregasi yang sama persis.

**Q: Berapa banyak kolom di sheet SUMMARY?**
A: Total 47 kolom (8 data jabatan + 39 data agregasi).

**Q: Apakah bisa membuat chart dari data ini?**
A: Ya, sangat mudah. Pilih data → Insert → Chart.

**Q: Apakah data real-time?**
A: Data sesuai dengan waktu export. Export ulang untuk data terbaru.

**Q: Apakah bisa filter per unit kerja?**
A: Ya, gunakan AutoFilter di Excel atau buat Pivot Table.
