# Quick Guide: Export Peta Jabatan dengan Agregasi

## ⚡ 3 Langkah Mudah

### 1️⃣ Export Peta Jabatan
```
Login → Peta Jabatan → Formasi ASN → Export Semua Unit
```

### 2️⃣ Buka File Excel
```
File akan diunduh: Peta_Jabatan_ASN_Semua_Unit_YYYYMMDD.xlsx
```

### 3️⃣ Lihat Sheet Agregasi
```
Scroll ke sheet paling akhir:
- Tabel Golongan per Unit
- Tabel Pendidikan per Unit
- Jumlah ASN per Unit
```

## 📊 Apa yang Ada di File?

### Sheet Utama
- **SUMMARY** - Ringkasan jabatan per unit kerja
- **28+ sheet** - Detail peta jabatan per unit kerja

### Sheet Agregasi (BARU!)
1. **Tabel Golongan per Unit** - Distribusi PNS & PPPK per golongan
2. **Tabel Pendidikan per Unit** - Distribusi pendidikan ASN
3. **Jumlah ASN per Unit** - Ringkasan ASN vs Non ASN

## 💡 Tips Penggunaan

### ✅ Untuk Laporan Cepat
```
1. Buka sheet "Tabel Pendidikan per Unit"
2. Copy tabel
3. Paste ke Word/PowerPoint
4. Laporan siap! ✅
```

### ✅ Untuk Analisis
```
1. Buka sheet "Tabel Golongan per Unit"
2. Lihat distribusi golongan per unit
3. Identifikasi unit dengan golongan tinggi
4. Rencanakan promosi/kenaikan pangkat
```

### ✅ Untuk Presentasi
```
1. Buka sheet "Jumlah ASN per Unit"
2. Copy tabel ke PowerPoint
3. Buat chart untuk visualisasi
4. Presentasikan ke pimpinan ✅
```

## ❓ FAQ

**Q: Berapa banyak sheet di file Excel?**
A: Total ~32 sheets (1 SUMMARY + 28 unit kerja + 3 agregasi).

**Q: Apakah data agregasi sama dengan Agregasi Cepat?**
A: Ya, menggunakan logika yang sama persis.

**Q: Apakah bisa copy tabel ke PowerPoint?**
A: Ya, sangat mudah. Pilih tabel → Copy → Paste ke PowerPoint.

**Q: Apakah data real-time?**
A: Data sesuai dengan waktu export. Export ulang untuk data terbaru.
